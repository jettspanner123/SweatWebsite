  <li>Locomotive Scroll</li>
</ul>

<h3>Project structure</h3>
<ul>
  <li><code>app/</code> – Next.js App Router (routes, layout, globals)</li>
  <li><code>components/</code> – Reusable UI (Navbar, PrimaryButton, MouseMagnetic, etc.)</li>
  <li><code>screens/</code> – Page-level screens (HomeScreen, FeaturesScreen)</li>
  <li><code>constants/</code> – App theme, colors, enums (application.ts)</li>
  <li><code>lib/</code> – External services (Firebase in firebase.ts)</li>
  <li><code>stores/</code> – Zustand state (pageState.ts)</li>
  <li><code>hooks/</code> – Custom hooks (useDimension.ts)</li>
  <li><code>assets/</code> – Images and static assets</li>
</ul>
